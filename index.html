PRACTICE 01 · 20분
⚖️
같은 질문, 다른 AI
상황/왜: 신입 직원에게 매번 VLOOKUP을 말로 설명하기 번거롭다면, AI에게 시켜서 품질을 비교해봅니다.
요청 방법: 같은 프롬프트를 ChatGPT·Claude·Gemini 3곳에 그대로 붙여넣습니다.
실행 단계: ① 프롬프트 복사 ② 3사 새 채팅창에 각각 붙여넣기 ③ 설명 순서·예제 품질 비교 ④ 평가표에 점수 기록
엑셀 함수 VLOOKUP을 처음 쓰는 직장인에게 설명해줘. 직원 정보 조회 예제 포함, 단계별로.
⏱ 20분 · 엑셀 평가표 활용
PRACTICE 02 · 20분
📊
엑셀 함수 자동 생성
상황/왜: IF 함수 구조를 매번 손으로 짜지 않고, 조건만 말로 설명해서 수식을 받아봅니다.
요청 방법: 조건(등급 기준)과 결과가 들어갈 셀 위치를 정확히 알려줍니다.
실행 단계: ① 프롬프트 입력 ② 받은 수식을 B2셀에 붙여넣기 ③ 채우기 핸들로 나머지 행 적용 ④ 결과 오류 있는지 확인
학생 점수가 A열에 있을 때,
90이상=A, 80이상=B, 70이상=C, 나머지=F를
B열에 넣는 IF 함수를 작성해줘.

PRACTICE 03 · 20분
